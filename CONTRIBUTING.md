# Contributing to Shekyl Foundation Discussions

Thank you for taking the time to participate in our community discussions! This guide explains how to get the most out of this space and help keep it useful for everyone.

## Before You Post

1. **Search first.** Use the search bar in the [Discussions tab](../../discussions) to check whether a similar topic already exists. Adding to an existing thread is often more valuable than opening a new one.
2. **Read the [Code of Conduct](CODE_OF_CONDUCT.md).** All participants are expected to follow it.
3. **Pick the right category.** Each discussion category has a specific focus — choosing the correct one helps the right people find and engage with your post.

## Opening a New Discussion

1. Navigate to the [Discussions tab](../../discussions) and click **New discussion**.
2. Select the category that best fits your topic:
   - **🛠 Development** — technical topics, engineering proposals, tooling, code standards
   - **🎨 GUI / UI-UX** — design reviews, accessibility, user experience improvements
   - **🌐 Website Content** — copywriting, page structure, content strategy
   - **💡 General** — everything else, including announcements and introductions
3. Fill in the discussion template provided for that category.
4. Use a clear, descriptive title that summarizes the topic at a glance.
5. Provide enough context so others can understand and engage without needing to ask follow-up questions.

## Writing a Good Discussion Post

- **Be specific.** Vague posts receive vague responses. Include relevant background, links, screenshots, or code snippets where helpful.
- **One topic per discussion.** Keep each thread focused on a single subject to make it easy to search and reference later.
- **Use formatting.** Markdown is supported — use headings, bullet points, and code blocks to improve readability.
- **Ask for what you need.** If you want feedback, a decision, or just an open conversation, say so upfront.

## Replying to Discussions

- **Be constructive.** Critique ideas, not people.
- **Stay on topic.** If a reply takes the discussion in a new direction, consider opening a separate thread.
- **Use reactions** (👍 👎 ❤️ etc.) to show agreement or support without adding noise to the thread.
- **Mark the answer.** If you opened a question-style discussion and a reply resolves it, mark it as the accepted answer.

## Discussion Etiquette

- Avoid posting the same message in multiple categories.
- Tag relevant people with `@mentions` sparingly and only when their input is genuinely needed.
- Keep self-promotion and off-topic advertising out of discussions.

## Questions?

If you're unsure where a topic belongs or have questions about the community, open a discussion in the **💡 General** category.

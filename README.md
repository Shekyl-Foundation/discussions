# Shekyl Foundation — Public Discussions

Welcome to the official organization-wide discussion space for the **Shekyl Foundation**. This repository is the central hub where community members, contributors, and team members can share ideas, ask questions, and collaborate openly on topics that shape the foundation and its projects.

## 💬 Discussion Categories

| Category | What belongs here |
|---|---|
| 🛠 **Development** | Architecture decisions, technical proposals, code standards, tooling, and engineering processes |
| 🎨 **GUI / UI-UX** | Design feedback, user experience ideas, accessibility improvements, and visual language discussions |
| 🌐 **Website Content** | Copywriting, page structure, content strategy, and improvements to our public-facing web presence |
| 💡 **General** | Anything that doesn't fit neatly into the above — organization-wide announcements, introductions, and open conversation |

## 🚀 How to Participate

1. **Browse existing discussions** using the [Discussions tab](../../discussions) before opening a new one — your question may already have an answer.
2. **Start a new discussion** by clicking **New discussion**, choosing the appropriate category, and filling in the provided template.
3. **Engage respectfully** — read our [Code of Conduct](CODE_OF_CONDUCT.md) before posting.
4. **Stay on topic** — keep each discussion focused on a single subject so threads remain useful over time.
5. **Mark helpful answers** — if a reply resolves your question, mark it as the accepted answer to help others.
